# Share & Export

## Share a report

Choose **Share** on a completed study, then **Create share link**.

- Anyone with the link can view the report, **read-only and without signing in**.
- A banner on the page marks it as a shared, read-only report.
- Choose **Stop sharing** at any time to disable the link. A revoked link shows "This shared report is not available".

> Treat the link like the report itself. Anyone it is sent to can read your content, audience and every reaction.

## Export

From a report you can download:

| Format | Use it for |
| --- | --- |
| **PDF** | Sending to colleagues or attaching to a document |
| **Word** | Editing the narrative and recommendations |
| **JSON** | Your own analysis; contains the full structured results |

If an export fails, try again. The report page itself is unaffected.

## Where the language comes from

The reactions, narrative and recommendations in a report are written in the language the study was run in, and the report says which. Exports use the same text.

## From an AI assistant

An assistant connected over [MCP](/ai/mcp.md) can read the same reports, create and revoke share links, and fetch the individual reactions.
