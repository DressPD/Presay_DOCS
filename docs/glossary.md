# Glossary

| Term | Meaning |
| --- | --- |
| **A/B test** | A study that shows two versions to the same panel and compares them. The sample size is per variant. See [Study Types](/studies/types.md). |
| **Accept / Revise** | The call at the top of a single-target report: use the content as it is, or change it first. See [Accept or Revise](/reports/decision.md). |
| **Analysed content** | The exact content each persona received, shown in the report's methodology section. |
| **Appeal** | How well the content grabs attention and earns a second look. 1 to 5. |
| **Audience** | The mix of age, gender, geography, income, education and area your panel is drawn from. See [Audience & Sample Size](/studies/audience.md). |
| **Bootstrap interval** | The range the mean moves across when the simulated personas are resampled many times. It is not a margin of error for a real population. |
| **Clarity** | How obvious it is what the content is and what to do next. 1 to 5. |
| **Concept test** | A study of one idea, feature or product concept. |
| **Directional signal** | A 0 to 100 summary of how favourably the panel reacted across all four metrics. Use it to compare versions, not as a forecast. |
| **Draft** | An improved version of your text or image built from a report's recommendations. See [Improve & Retest](/drafts/retest.md). |
| **FDR correction** | The correction applied to segment differences so that checking many segments and metrics does not produce false highlights. |
| **MCP** | Model Context Protocol, the standard that lets an AI assistant use Presay on your behalf. See [Connect an Assistant](/ai/mcp.md). |
| **Messaging test** | A study of one headline, description or piece of copy. |
| **Panel** | The set of synthetic personas generated for one study. |
| **Persona** | A simulated respondent with a demographic profile and a personality. Also called a respondent. Not a real person. |
| **Preset** | A saved audience mix. Prebuilt presets are maintained by Presay. |
| **Relevance** | How directly the content speaks to the persona's situation and needs. 1 to 5. |
| **Sample size (n)** | The number of personas, from 1 to 500. |
| **Segment** | A group within the panel, such as an age band, gender or area. Segments with fewer than 5 personas are hidden. |
| **Study** | One run of a target against a panel. It counts once against your allowance. |
| **Study allowance** | The rolling limit on studies per account: 30 a week and 10 a day. See [Study Allowance](/account/limits.md). |
| **Target** | The content personas react to: a URL, text, image, document, audio or video. |
| **Trust** | How credible the content feels enough to believe and act on. 1 to 5. |
