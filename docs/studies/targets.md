# Choosing a Target

The target is what the personas react to. It is rendered once and shown identically to every persona in the study.

| Target | What to provide | How it is read |
| --- | --- | --- |
| **URL** | A web page address | The page is rendered and shown as a screenshot plus its text |
| **YouTube** | A video URL | Reviewed from the video |
| **Text** | Pasted copy | Read as written |
| **Image** | An uploaded image | Analysed directly |
| **Audio / Video** | An uploaded file | Transcribed before review |
| **Document** | An uploaded file | Read as text, up to 30,000 characters |

Accepted file types: PNG, JPG, GIF, WebP, MP3, M4A, MP4, WAV, OGG, WebM, FLAC, MOV, AVI, MKV, PDF, DOCX, HTML and MD.

## Tips

- **Pick the shape you will ship.** A headline test needs the headline, not the whole page.
- **Add context for images.** A single image cannot show a size guide, price details or other sections of a page. If the report says information is "missing", it may only be missing from that image. Add more images so personas judge them together as one offering.
- **Use an image test for visual design.** If Presay cannot capture a screenshot of a URL, personas judge its text only and the report says so. Paste a screenshot as an image test to judge layout and design.
- **URLs must be reachable.** Presay needs to open the page. If it cannot (for example a page that needs you to sign in), paste the text or upload a screenshot instead.
- **Edit the original, not the report.** To test a change, make a new study or use [Improve & Retest](/drafts/retest.md).

> Scoring from images, whether an upload or a page screenshot, has not been checked against real ratings as thoroughly as text. See [Limits](/limits.md).

## Duplicating a study

Use **Duplicate** on a study to copy its audience, sample size and target into a new study, then change what you need. Uploaded files cannot be copied, so reselect the original file.
