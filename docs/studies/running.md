# Running & Managing Studies

## Running a study

Choose **Run study** on **New study**. A study of 20 to 30 personas usually takes about a minute. Larger ones show an estimate on the form, such as "About 4 min". The study keeps running if you close the page, and a progress bar shows where it is.

Each run uses one study from your weekly and daily [allowance](/account/limits.md). The form shows how many you have left, and blocks the run with an explanation if you are at the limit.

If fewer personas than requested return a usable response, the report says so and computes every figure from the ones that did.

## The Studies list

**Studies** lists everything you have run, with name, audience, type, status and dates. You can:

- Search by name and filter by **Status**.
- Open a study to read its report.
- **Duplicate** a study into a new one.
- **Delete** a study. This removes the study, its report and all of its reactions and cannot be undone.

## Names

Name a study when you create it so the list stays readable. A name like "Homepage redesign v2" is easier to find than the default.

## Re-running

Studies are simulations, so re-running the same content can give slightly different numbers. The report's intervals are widened to reflect run-to-run variation where that has been measured. To compare versions fairly, run them as one [A/B test](/studies/types.md) on the same panel rather than as two separate studies.
