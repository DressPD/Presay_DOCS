# Study Types

Choose the type on the first step of **New study**. The type decides how many targets you add and how the report compares them.

| Type | Use it to | Targets |
| --- | --- | --- |
| **A/B test** | Compare two versions of a page, design or text | Two variants, A and B |
| **Concept test** | Test an idea, feature or product concept | One |
| **Messaging test** | See how one headline, description or piece of copy lands | One |

## Single-target studies

Concept and messaging tests show one target to every persona. The report leads with an [accept-or-revise decision](/reports/decision.md) and quotes the passages behind each recommendation.

## A/B tests

An A/B study shows both variants to the same panel. The sample size you set is the number of personas **per variant**, and the report says how many personas scored both.

- The report compares each metric as a **paired difference** and marks differences that are significant.
- Seeing both variants together makes differences look bigger. Use the result to pick a winner, not to read absolute scores.
- Variants can be URLs, text or images. When you upload files, each variant is one image and both together must stay within the size limit.
- If the two variants are mostly the same text, the report warns that the difference is mostly wording. If the gap is no larger than what the same text scores against itself, do not read it as a real preference.

## Study templates

The public page offers three ready-made study shapes you can start from, then tailor:

- **First-pass clarity**: find out whether a new page makes sense before you invest in traffic.
- **Pre-flight a concept**: screen a visual or thumbnail for appeal, trust and relevance across key age groups.
- **Pressure-test a claim**: paste a headline, value proposition or subject line and see where the message splits.
