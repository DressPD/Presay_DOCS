# Audience Library

**Audiences** in the main navigation lists the audience groups you can use in studies.

## Prebuilt and custom

| Type | What it is |
| --- | --- |
| **Prebuilt** | Presets maintained by Presay, such as general-population mixes by country |
| **Custom** | Audiences you created or imported |

Filter by **Type**, **Country** or **Demographic dimension**, or search by name. Select an audience to see its **Demographic breakdown**: age, gender split and top regions.

## Actions

- **Use in new study** starts a study with that audience.
- **Duplicate** copies an audience so you can change it.
- **Delete** removes a custom audience.
- **Create audience** builds a new one from your own mix, see [Audience & Sample Size](/studies/audience.md).

## Things to know

- **Saved audiences cannot be edited or renamed.** Duplicate one to make a new definition.
- **Saved audiences hold demographics only.** Relationship and brand-awareness attributes are study settings on **New study**.
- **There is no fixed panel.** A synthetic audience is generated per study, so an audience has no fixed size. Each study draws its own personas from the mix.
- **Prebuilt audiences are managed by Presay**, so their detailed weights may not all be shown.

[Import audiences from a spreadsheet](/audiences/import.md) if you already hold the mix in a file.
